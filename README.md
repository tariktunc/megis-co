# Megis

**Domain:** https://megis.co *(DNS bağlantısı bekleniyor)*  
**Vercel:** https://megis.vercel.app  
**GitHub:** https://github.com/tariktunc/megis.co

---

Megis — Dijital Ajans. Web, tasarım ve dijital çözümler.

## Sayfalar

- `/` — Ana sayfa
- `/[locale]/blog` — Blog (çok dilli)
- `/api/contact` — İletişim API

## Tech Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- next-intl (çok dilli)
- Framer Motion
- GSAP + Lenis (animasyon)
- React Three Fiber (3D)
- Zustand

## Kurulum

```bash
npm install
npm run dev
```
